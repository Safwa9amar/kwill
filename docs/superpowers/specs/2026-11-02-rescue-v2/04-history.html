Restore
Bringing an old version back adds a new version on top and deletes nothing, so the student can always undo it.

What a version is

  • A saved rescue run: the settings snapshot (rules, note, answers, cover), the output .docx + PDF, the page images, the change list, and its parent version.
  • Immutable. Edit means a new run; restore means a new version on top.
  • The original (v0) is never deleted, only with the whole thesis.

Edits from the Kwill editor

  • If the student opens a version and writes, the timeline shows "edited in Kwill" (detected from the document hash).
  • The next re-run sees those edits as changed blocks: only they are re-mapped and re-checked, and old answers stay.
  • Undo inside the editor keeps using the existing history; the timeline only records rescue-level steps.

Cost and storage

  • Compare and preview reuse the page images saved with each version, so there's no new conversion and no model call.
  • A re-run only pays for the changed blocks and pages, which keeps the free promise affordable.
  • About 5 MB per version (docx + PDF + thumbnails). Keep all versions until the student deletes the thesis.
